# Automated Containerized CI/CD Deployment Pipeline

Production-grade CI/CD pipeline using FastAPI, Pytest, multi-stage Docker builds, Docker Hub, and automated SSH zero-downtime deployment.

## Architecture
- **Web API:** FastAPI (Python 3.11)
- **Testing:** Pytest & HTTPX
- **Containerization:** Multi-stage Dockerfile
- **CI/CD:** GitHub Actions
- **Registry:** Docker Hub
- **Host:** Linux / AWS EC2
